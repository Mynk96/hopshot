Snipping Tool not working? Fix it by what you see

By Mayank Harsani, maker of Hopshot · Updated 27 November 2026

When Snipping Tool, Win Shift S or Print Screen stops working on Windows 11 or 10, it's usually one of four things: the app is stuck in the background, the shortcut belongs to another app, a setting changed in an update, or the snip worked and went somewhere you didn't expect. Quickest test first: press Win PrtSc. If the screen dims and a file appears in Pictures → Screenshots, Windows can capture fine and the problem is Snipping Tool or its shortcut. Then find what you're seeing below.

Win+Shift+S does nothing, or works once and then stops

  1. Check that Snipping Tool itself works. Open Snipping Tool from the Start menu and click New. Or press Win R, type ms-screenclip: and press Enter, which opens the same overlay as the shortcut. If either works, the tool is fine and only the shortcut is stuck.
  2. Stop Snipping Tool and start again. Open Settings → Apps → Installed apps, click the … next to Snipping Tool, choose Advanced options and click Terminate. Then try the shortcut. This is the fix for the "works once, then nothing" pattern people report in Microsoft's forums.
  3. Restart Windows Explorer. Press Ctrl Shift Esc, find Windows Explorer under Processes, right-click it and choose Restart. The taskbar blinks off and comes back. Explorer handles many Win key shortcuts, so a stuck Explorer can swallow them.
  4. Turn Snipping Tool notifications on. Open Settings → System → Notifications and make sure notifications are on, both overall and for Snipping Tool. The snip still works without them, but you won't see the preview you click to edit or save it, so it can look as if nothing happened.
  5. Check for a remapped key. PowerToys Keyboard Manager, gaming keyboard software and some remote-desktop tools can capture Win key shortcuts. Turn them off one at a time and test.
  6. Restart the PC. If the shortcut only works after a restart and then stops again, update the app as described in the next section.

Snipping Tool won't open, or closes straight away

  1. Repair, then reset. Open Settings → Apps → Installed apps, click the … next to Snipping Tool and choose Advanced options. Click Repair first, which keeps your settings. If that doesn't help, click Reset, which clears the app's settings and data.
  2. Update it. Open the Microsoft Store, go to Library, and click Get updates. Snipping Tool is updated through the Store, separately from Windows. Also install anything waiting in Settings → Windows Update.
  3. Reinstall it. Uninstall Snipping Tool from Installed apps, restart, then search for "Snipping Tool" in the Microsoft Store and install it again.
  4. Repair Windows system files. Right-click Start, choose Terminal (Admin), and run these one after the other. Each can take several minutes: 
    DISM /Online /Cleanup-Image /RestoreHealth
sfc /scannow
  5. On a work PC, your IT team can block Snipping Tool with a policy. If you see a message that an administrator blocked the app, ask them. Reinstalling won't get around it.

Print Screen does nothing, or opens the wrong thing

  1. Check the Print Screen setting. On Windows 11, Print Screen opens the snipping overlay by default. The switch is Use the Print screen key to open screen capture. On current Windows 11 it's in Settings → Bluetooth & devices → Keyboard; on older builds it's in Settings → Accessibility → Keyboard. Turn it on to make Print Screen open the overlay, or off to make it copy the whole screen to the clipboard as Windows 10 did. Restart after changing it.
  2. Laptop keyboards: Print Screen often shares a key with something else. Try Fn PrtSc, and check whether an Fn Lock or F Lock key is on.
  3. Another app took the key. Snagit, Greenshot, ShareX, Lightshot and Dropbox can all claim Print Screen. If one of them opens instead, or Print Screen does nothing at all, quit those apps one at a time, or change the key inside that app.
  4. The switch is missing or ignored. Windows stores it in the registry as PrintScreenKeyForSnippingEnabled under HKEY_CURRENT_USER\Control Panel\Keyboard: 1 opens the overlay and 0 doesn't. Change it only if the Settings switch isn't there, then sign out and back in. Back up the registry first.

Whatever the setting, Win PrtSc still saves the whole screen to Pictures → Screenshots, and Alt PrtSc copies just the active window. More shortcuts are in how to screenshot on Windows.

You took a snip but can't find it

  • It's on the clipboard. Win Shift S always copies the snip, so paste it with Ctrl V. Turn on clipboard history with Win V to get back snips you copied over.
  • Auto-save is off. In Snipping Tool, click See more (the three dots) → Settings and turn on Automatically save screenshots. Snips then save to Pictures\Screenshots as well as the clipboard.
  • Your Pictures folder is in OneDrive. If OneDrive backs up your Pictures folder, screenshots land in OneDrive\Pictures\Screenshots instead. To check, open the OneDrive icon → Settings → Sync and backup → Manage backup. Microsoft removed OneDrive's separate "save screenshots" switch, so the folder backup is what decides it now.
  • Search for it. Open File Explorer, go to Pictures, and sort by Date modified, or search for Screenshot.

The snip won't paste

  • Paste straight away. The clipboard holds one image, and copying anything else replaces it. Win V clipboard history keeps the earlier ones.
  • Some apps need a different key. In Windows Terminal, Ctrl V pastes text only, so image paste in tools like Claude Code uses Alt V. See pasting screenshots into Claude Code on Windows.
  • The app wants a file. Some upload boxes and remote desktops won't take a pasted image. Save the snip (Ctrl S in Snipping Tool) and drag the file in.

The snip is black, or shows the wrong part of the screen

  • Black where a video or app was: streaming video and some apps (banking, password managers, protected meetings) block screen capture on purpose, so that area comes out black. There's no setting to change this.
  • Wrong area or blurry on a second monitor: this usually happens when monitors use different scaling. Check Settings → System → Display → Scale for each monitor, try setting them the same, and update your graphics driver.
  • Snip from the wrong monitor: the overlay covers every screen, so move the mouse to the monitor you want before you drag.

Still on Windows 10?

Win Shift S on Windows 10 belongs to the Snip & Sketch app. The fixes above apply: terminate or reset the app in Settings → Apps, check notifications, and update it from the Microsoft Store. Windows 10 stopped getting regular security updates on 14 October 2025, so some app bugs there won't be fixed. Win PrtSc still works as a fallback.

FAQ

Why is my Snipping Tool not working?

Usually Snipping Tool is stuck in the background, another app has taken its shortcut, or an update changed a setting. Open Settings, Apps, Installed apps, Snipping Tool, Advanced options and click Terminate, then try again. If the app won't open at all, use Repair, then Reset, on the same page, and update it from the Microsoft Store.

Why is Windows Shift S not working?

Check that Snipping Tool opens from the Start menu first. If it does, terminate it in Settings, Apps, Installed apps, Snipping Tool, Advanced options, restart Windows Explorer from Task Manager, and make sure Snipping Tool notifications are on in Settings, System, Notifications. Tools like PowerToys can also remap the shortcut.

Why does Print Screen not work on Windows 11?

On Windows 11 the Print Screen key opens the snipping overlay when Use the Print screen key to open screen capture is on, in Settings, Bluetooth and devices, Keyboard (Accessibility, Keyboard on older builds). On laptops try Fn plus PrtSc. Apps like Snagit, Greenshot, ShareX and Lightshot can also take the key.

Where do Snipping Tool screenshots go?

Every snip is copied to the clipboard. With Automatically save screenshots turned on in Snipping Tool's settings, it is also saved to Pictures, Screenshots. If OneDrive backs up your Pictures folder, look in OneDrive, Pictures, Screenshots instead.

How do I reset Snipping Tool?

Open Settings, Apps, Installed apps, click the three dots next to Snipping Tool and choose Advanced options. Try Repair first, which keeps your settings, then Reset, which clears them. If it still fails, uninstall it and install Snipping Tool again from the Microsoft Store.
