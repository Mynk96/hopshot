How to screenshot on Mac: every shortcut, on any macOS version

By Mayank Harsani, maker of Hopshot · Updated 26 November 2026

To screenshot on a Mac, press ⌘ Shift 4 and drag over the area you want. To capture the whole screen, press ⌘ Shift 3. Both save a PNG to your Desktop. Add Control to either shortcut to copy the screenshot to the clipboard instead, then paste it with ⌘ V.

These shortcuts work on every MacBook Air, MacBook Pro, iMac, Mac mini and Mac Studio, and on every version from old Mac OS X releases to macOS 27 Golden Gate. Below: every shortcut, how to capture a window, a menu or a whole web page, what changes on older versions, and the Terminal commands.

Tip: ⌘ is the Command key. On a Mac there is no Print Screen key; these shortcuts are the Mac's version of it. You can change any of them in System Settings → Keyboard → Keyboard Shortcuts → Screenshots.

How to screenshot part of the screen

  1. Press ⌘ Shift 4. The pointer turns into a crosshair.
  2. Drag over the area you want.
  3. Let go. A thumbnail slides into the bottom-right corner for a few seconds, then the file is saved to your Desktop.

While you drag, three keys change the selection:

  • Hold Space to move the whole box without resizing it.
  • Hold Shift to lock one edge, so you resize only the width or only the height.
  • Hold Option to resize the box from its centre.

To paste the screenshot straight into an email, chat or AI tool without saving a file, press ⌘ Control Shift 4 instead, then ⌘ V.

How to screenshot the whole screen

Press ⌘ Shift 3. If you use more than one display, you get one file per display. To capture only one of them, press ⌘ Shift 5, choose Capture Entire Screen and click the display you want.

How to screenshot one window or a menu

  1. Press ⌘ Shift 4, then press Space. The pointer turns into a camera.
  2. Move it over a window so the window is highlighted, then click.
  3. Hold Option while you click to leave out the window's shadow.

For a menu: open the menu first, then press ⌘ Shift 4 and drag over it, or press Space and click the menu to capture just the menu. Some apps, such as the Apple TV app, don't allow screenshots of their windows; you get a blank area instead.

How to take a screenshot with a timer

  1. Press ⌘ Shift 5 and click Options.
  2. Under Timer, pick 5 or 10 seconds.
  3. Choose what to capture, click Capture, then open the menu or hover the tooltip you want while the timer counts down.

The timer stays on for later screenshots taken from the toolbar until you set it back to None.

How to screenshot a whole web page on Mac

The built-in tool only captures what's visible. For a page that scrolls:

  • Firefox: right-click the page, choose Take Screenshot, then Save full page.
  • Chrome: press ⌘ Option I to open DevTools, then ⌘ Shift P, type full size screenshot and press Enter.
  • Safari: choose File → Export as PDF to keep the whole page as one PDF.

How to screenshot on a MacBook

MacBook Air and MacBook Pro use exactly the same shortcuts as a desktop Mac; you don't need Fn. A few MacBook-specific points:

  • No Print Screen key: use ⌘ Shift 3 (whole screen) or ⌘ Shift 4 (part of it).
  • Touch Bar models: ⌘ Shift 6 captures the Touch Bar itself. You can also add a Screenshot button to the Touch Bar in System Settings → Keyboard → Touch Bar Settings.
  • Using a Windows keyboard with your Mac? Its Print Screen key does nothing by default. In System Settings → Keyboard → Keyboard Shortcuts → Screenshots, double-click a shortcut and press the key you want to use instead.
  • Without the keyboard: open Launchpad or Spotlight, search for Screenshot and use the toolbar with the trackpad.

Screenshots on older Mac OS X and macOS versions

⌘ Shift 3 and ⌘ Shift 4 have worked the same way for a very long time. What changes between versions is the toolbar and a few options.

VersionWhat's different
macOS 26 Tahoe and macOS 27 Golden GateOptions adds Capture Format: HDR screenshots are saved as HEIF on supported Macs, SDR as PNG.
macOS 10.14 Mojave to macOS 15 Sequoia⌘ Shift 5 toolbar, the floating thumbnail and the Screenshot app (Applications → Utilities) all arrived in Mojave.
macOS 10.13 High Sierra and older Mac OS XNo ⌘ Shift 5. For a timed screenshot, use Grab in Applications → Utilities, or Preview's File → Take Screenshot.

Recent versions name files "Screenshot [date] at [time].png"; older ones used "Screen Shot [date] at [time]", so search for both when you look for an old file. If you're not sure which version you have, open the Apple menu → About This Mac.

On macOS 27 with Apple Intelligence turned on, Apple's own guide also lists ⌘ Shift 6 as a way to ask Siri about part of the screen, so that shortcut may not take a Touch Bar screenshot there.

Where Mac screenshots are saved

By default, on the Desktop. Shortcuts with Control don't save a file at all, and if you dragged the floating thumbnail into an app, the file goes there instead. To check or change the folder, press ⌘ Shift 5 → Options → Save to. More detail, including how to find a screenshot that seems to have vanished: where do screenshots go on Mac.

Screenshot commands and settings

Take a screenshot from Terminal

The screencapture command is built into every Mac:

  • Select an area, like ⌘ Shift 4: screencapture -i ~/Desktop/shot.png
  • Whole screen to the clipboard: screencapture -c
  • Whole screen after 5 seconds: screencapture -T 5 ~/Desktop/shot.png

Add -x to turn off the shutter sound. Run man screencapture for every option.

Save as JPG instead of PNG

defaults write com.apple.screencapture type jpg
killall SystemUIServer

Use png to switch back. PNG keeps text sharp; JPG files are smaller.

Change the file name

defaults write com.apple.screencapture name "Capture"
killall SystemUIServer

Screenshots are now named "Capture [date] at [time]".

Turn off the floating thumbnail

Press ⌘ Shift 5 → Options and untick Show Floating Thumbnail. The file is then saved immediately instead of after a few seconds.

Screenshot not working?

  • The shortcut does nothing: check it's ticked in System Settings → Keyboard → Keyboard Shortcuts → Screenshots, and that another app hasn't taken it.
  • The file never appears: check Options → Save to. If it says Clipboard, nothing is saved.
  • Black or wallpaper-only screenshots: the app you're capturing blocks screenshots, or a third-party screenshot app lacks Screen Recording permission.

Where the built-in Mac screenshot tool falls short

  • The Desktop fills up. Every screenshot is a separate file, and nothing ever deletes them.
  • The thumbnail is fragile. It disappears after a few seconds, and if you drag it somewhere that won't take the drop, the screenshot can be lost.
  • The clipboard holds one image. Three screenshots for one message means capture, paste, capture, paste.
  • Your phone is a separate trip. AirDrop works for iPhone; for Android it means emailing yourself.

FAQ

How do I take a screenshot on a Mac?

Press ⌘ Shift 4 and drag over the area you want, or press ⌘ Shift 3 for the whole screen. The screenshot is saved to your Desktop. Add Control to copy it to the clipboard instead.

What is Print Screen on a Mac?

Macs have no Print Screen key. ⌘ Shift 3 does the same job: it captures the whole screen. ⌘ Control Shift 3 copies it to the clipboard, like Print Screen on Windows.

How do I screenshot on a MacBook Air or MacBook Pro?

Use the same shortcuts as any Mac: ⌘ Shift 3 for the whole screen, ⌘ Shift 4 for part of it and ⌘ Shift 5 for the toolbar. You don't need the Fn key.

How do I take a screenshot on Mac OS X?

⌘ Shift 3 and ⌘ Shift 4 work on old Mac OS X versions too. Before macOS Mojave there is no ⌘ Shift 5 toolbar; use the Grab app in Applications → Utilities or Preview's File → Take Screenshot for timed captures.

How do I screenshot just one window on a Mac?

Press ⌘ Shift 4, then Space, and click the window. Hold Option while clicking to leave out the shadow.

How do I copy a screenshot instead of saving it?

Add Control: ⌘ Control Shift 4 copies a selected area and ⌘ Control Shift 3 copies the whole screen. Paste with ⌘ V. To make this the default, press ⌘ Shift 5 → Options → Save to → Clipboard.

Where do screenshots go on a Mac?

To the Desktop by default, named "Screenshot [date] at [time].png". Change the folder in ⌘ Shift 5 → Options → Save to.

How do I take a scrolling screenshot on a Mac?

The built-in tool can't. In Firefox, right-click → Take Screenshot → Save full page. In Chrome, use DevTools' "Capture full size screenshot" command. In Safari, use File → Export as PDF.
