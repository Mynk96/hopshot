How to paste screenshots into Claude Code on Windows (when Ctrl+V does nothing)

By Mayank Harsani, maker of Hopshot · 17 November 2026

On Windows, press Alt+V instead of Ctrl+V to paste a screenshot into Claude Code. If that fails too, drag the image file into the terminal. Here's why it happens and how to make it reliable.

Why Ctrl+V doesn't work

Windows Terminal uses Ctrl+V for its own paste command. It catches the keystroke before Claude Code sees it, so the image never arrives. Text still pastes, which makes it look like an image bug.

There's a nastier version. Sometimes Claude Code shows an [Image #1] chip, but the screenshot never reached the model. The model then says it can't see the image, and you blame the model.

Fix 1: Use Alt+V

Alt+V is Claude Code's documented image-paste key for terminals that intercept Ctrl+V.

  1. Press Win+Shift+S and select an area.
  2. Click into the Claude Code prompt.
  3. Press Alt+V.

If the first Alt+V right after a snip does nothing, wait a second and press it again. Several users report the first press failing on a fresh snip.

Fix 2: Check your Windows Terminal key bindings

Open Windows Terminal settings, choose Open JSON file, and look for a binding like "keys": "ctrl+v". Removing a custom Ctrl+V binding can restore image paste. Back up the file first.

Fix 3: Drag the file in

Dragging an image file into the terminal is the most reliable route. Windows Terminal inserts the file's path and Claude Code attaches the image.

The catch: Win+Shift+S only puts the image on the clipboard. You have to save it, find it in File Explorer and drag it over. After a few rounds your Pictures folder fills with Screenshot 2026-…png files.

FAQ

Does this work in the VS Code terminal?

Yes. Alt+V and drag-and-drop work there too. If Ctrl+V pastes text instead of an image, use Alt+V.

Does it work in WSL?

WSL often can't read images from the Windows clipboard. Dragging a file into the WSL tab in Windows Terminal is the dependable route.

Can I add several screenshots to one prompt?

Yes. Drag them in one after another; each stays on the shelf until it expires.

Can I change Hopshot's capture shortcut?

Yes. Ctrl+Shift+2 is the default and you can pick another in Settings.
