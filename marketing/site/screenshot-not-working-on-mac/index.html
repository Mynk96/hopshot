Mac screenshot not working? Fix it by what you see

By Mayank Harsani, maker of Hopshot · Updated 25 November 2026

Most Mac screenshot problems come from four causes: the shortcut is switched off or taken by another app, the save location points somewhere that no longer works, the floating thumbnail swallowed the file, or the screenshot settings got into a bad state after an update. Find what you're seeing below and try the fixes in order. Quickest test first: press ⌘ Shift 5. If the Screenshot toolbar opens, the screenshot tool works and the problem is the shortcut or where files go.

The shortcut does nothing

  1. Check the shortcuts are on. Open System Settings → Keyboard → Keyboard Shortcuts → Screenshots. Make sure the boxes are ticked and the keys are the ones you're pressing (⌘ Shift 3, 4 and 5 by default). If they look wrong, click Restore Defaults.
  2. Another app took the shortcut. Screenshot and clipboard apps (Dropbox's screenshot feature, CleanShot X, Snagit, Shottr and others) can claim ⌘ Shift 4. Quit them one at a time and try again, or change the shortcut inside that app.
  3. Use the Screenshot app instead. Open Applications → Utilities → Screenshot (or search "Screenshot" in Spotlight). If it works from there, the tool is fine and only the shortcut is the problem.
  4. Restart the Mac. A stuck screenshot service clears more often than you'd expect.

You hear the shutter, but no file appears

The screenshot was taken; it just didn't land where you're looking.

  1. Check where screenshots go. Press ⌘ Shift 5 → Options. If Save to is set to Clipboard, nothing is saved (paste with ⌘ V). If it's Preview, Mail or Messages, the screenshot opens in that app instead of becoming a file. Choose Desktop to get files again. More on this in where screenshots go on a Mac.
  2. Did you use Control? Any shortcut with Control (like ⌘ Control Shift 4) copies to the clipboard only.
  3. Did you touch the thumbnail? Dragging the floating thumbnail into an app hands the image over without saving a file. Swiping it away discards the screenshot.
  4. Turn off the floating thumbnail. ⌘ Shift 5 → Options → untick Show Floating Thumbnail. The file is then saved straight away. Several people in Apple's forums fixed "screenshots stopped saving" after a macOS update this way.
  5. Reset the file format. If someone changed the screenshot format in Terminal, an unusual value can stop files from saving. This puts it back to PNG: 
    defaults delete com.apple.screencapture type
killall SystemUIServer
  6. Search for it. Finder → Recents, sorted by date, shows the newest screenshots wherever they went. Or list every screenshot on the Mac in Terminal: 
    mdfind "kMDItemIsScreenCapture == 1"

"Your screenshot can't be saved"

macOS took the screenshot but couldn't write the file to the save location. Usually that folder was deleted or renamed, sits on an external drive that isn't connected, or is a folder you can't write to.

  1. Press ⌘ Shift 5 → Options and choose Desktop, or pick a folder that exists with Other Location…
  2. Check the location macOS is using: 
    defaults read com.apple.screencapture location
    If it prints a folder that no longer exists, set it again (or remove it, which goes back to the Desktop): 
    defaults delete com.apple.screencapture location
killall SystemUIServer
  3. Make sure the Mac isn't out of disk space: Apple menu → System Settings → General → Storage.

The screenshot is black, or shows only your wallpaper

  • Black where a video was: streaming apps and some browsers protect video, so screenshots of it come out black. That's by design and there's no setting to change it.
  • Only the wallpaper, no windows: this happens with third-party screenshot apps that don't have permission to record the screen. Open System Settings → Privacy & Security → Screen & System Audio Recording and switch the app on, then quit and reopen it. The built-in tool doesn't need this permission.

The thumbnail won't drag, or disappears

Some people found thumbnail dragging stopped working after a macOS update. Turning Show Floating Thumbnail off, taking a screenshot, then turning it back on fixed it for many. We cover this, and Dropbox replacing the thumbnail, in Mac screenshot thumbnail won't drag.

Still broken? Reset everything

This resets all screenshot settings (save location, format, thumbnail, timer) to Apple's defaults:

defaults delete com.apple.screencapture
killall SystemUIServer

Then restart the Mac and test with ⌘ Shift 4. If it still fails, start up in Safe Mode and test again: if screenshots work there, a login item or another app is interfering. On a work Mac, your IT team's device management can also restrict screen capture.

FAQ

Why is my screenshot not working on my Mac?

Usually the shortcut is switched off or taken by another app, the save location points to a folder that's gone, or the screenshot went to the clipboard or a dragged thumbnail instead of a file. Press Command Shift 5: if the toolbar opens, the tool works and the problem is the shortcut or where files are saved.

Why does my Mac make the screenshot sound but not save it?

Check Command Shift 5 → Options → Save to. Clipboard means no file is saved, and Preview, Mail or Messages open the screenshot in that app instead. Turning off Show Floating Thumbnail also helps when screenshots stopped saving after a macOS update.

How do I fix "Your screenshot can't be saved" on Mac?

macOS can't write to the save folder, usually because it was deleted, renamed or is on a disconnected drive. Choose Desktop or another existing folder under Command Shift 5 → Options, or reset the location in Terminal with defaults delete com.apple.screencapture location, then killall SystemUIServer.

How do I reset screenshot settings on a Mac?

Run defaults delete com.apple.screencapture and then killall SystemUIServer in Terminal. This puts the save location, file format, floating thumbnail and timer back to Apple's defaults. You can also restore the keyboard shortcuts in System Settings → Keyboard → Keyboard Shortcuts → Screenshots.

Why are my Mac screenshots black?

Protected video, such as streaming apps, shows up black in screenshots by design. If a third-party screenshot app captures only your wallpaper, give it Screen Recording permission in System Settings → Privacy & Security.
